# ApplyTrack — Internship Application Tracker

A small React + Vite portfolio project for tracking internship applications.

## Features
- Add and delete applications
- Update status: Saved, Applied, Interview, Rejected or Offer
- Search by company or role
- Filter by status
- Summary counts
- Persist data in localStorage
- Responsive layout

## Run locally
```bash
npm install
npm run dev
```

## Scope
Front-end demo only. Data is stored in the current browser; there is no authentication, shared database or server sync.
