# TaskFlow — Task Board

A responsive task manager built with semantic HTML, CSS and vanilla JavaScript.

## Features
- Create, complete and delete tasks
- Filter all, active and completed tasks
- Priority labels
- Persistent browser storage with localStorage
- Responsive layout and basic accessible labels

## Run
Open `index.html` in a modern browser. No build step or dependencies.

## Scope
This is a front-end portfolio project. Tasks are stored locally in the current browser; there is no server-side sync or authentication.
