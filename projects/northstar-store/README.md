# Northstar — Storefront UI

A responsive product catalogue demo built with HTML, CSS and vanilla JavaScript.

## Features
- Product search
- Category filtering
- Price sorting
- Add-to-cart interaction and running total
- Responsive product grid

## Run
Open `index.html` in a modern browser. No build step or dependencies.

## Scope
This is a front-end demo using sample products and prices. It does not implement checkout, payments, authentication or a backend.
